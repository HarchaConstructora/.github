# .github

Repositorio de configuración a nivel de organización de **HarchaConstructora**.

## Contenido

| Ruta | Qué hace |
|---|---|
| [`profile/README.md`](profile/README.md) | Perfil público que GitHub muestra en [github.com/HarchaConstructora](https://github.com/HarchaConstructora) |

## Cómo funciona

GitHub trata este repositorio como especial: el archivo `profile/README.md` se renderiza
automáticamente en la portada de la organización. Cualquier cambio en `main` se refleja ahí
de inmediato.

Los archivos en la raíz de este repo (como este `README.md`) solo se ven al entrar al
repositorio, no en el perfil de la organización.

Más adelante este repo también puede alojar plantillas compartidas de issues, pull requests
y workflows reutilizables para toda la organización.
